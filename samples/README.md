# 示例文件

拿来就能试用文枢的几份客服场景数据。内容全部是虚构的，不含真实个人信息。

| 文件 | 内容 | 怎么用 |
|---|---|---|
| `客服对话-意图识别.xlsx` | 工作表“对话”120 行：会话ID、用户问题、时间、渠道。覆盖咨询、办理、投诉、建议、其他五类，含 6 行重复问题和 2 行空问题；另有工作表“说明” | 拖进首页 → 工作表选“对话” → 自动推荐“用户问题”列 → 意图识别 |
| `客服对话-意图识别.csv` | UTF-8 带 BOM、逗号分隔，100 行，比 xlsx 多一列“客户等级”；第 8 条数据的“用户问题”是引号内带换行的两行文字 | 拖进首页 → 意图识别。可以在提示词里用 `{{col:客户等级}}` 试试列变量 |
| `客服长文本-文本摘要.txt` | 10 行，每行一篇客服记录：投诉信、退款纠纷通话纪要、会员续费争议、售后维修周报（约 3,600 字）、发票问题、账号被盗申诉、积分清零投诉、夜班通话纪要汇总（约 3,000 字）、用户建议汇总、宽带安装改期 | 拖进首页 → 文本摘要 → 完成后点开某行进入对照阅读 |

## 小提示

- 不接入真实模型也能完整跑通：默认用的是内置演示模型，结果是模拟的（意图从提示词列出的类别里选，文本里出现了哪个类别名就选哪个）。
- 想看到长文本的**分段摘要再合并**：在“模型”页编辑演示模型，把上下文长度改成 4096，再对 `客服长文本-文本摘要.txt` 做摘要，售后维修周报和夜班通话纪要会被分成几段。
- xlsx 里的“相同文本只调用一次”：预估页会显示能省下多少次调用；空问题的行会自动跳过并计数。

## 重新生成

这些文件由 `make_samples.py` 生成（只用标准库，随机数固定种子，每次结果相同）：

```bat
backend\.venv\Scripts\python.exe samples\make_samples.py
```

同一个脚本还会写出端到端测试用的 `frontend\e2e\fixtures\intent_200.xlsx`（结构见 `docs/08-plan-and-acceptance.md` 第 10.2 节）。
